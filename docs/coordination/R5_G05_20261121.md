## Plataforma, seguridad y privacidad

T05 utiliza Windows Job Objects. T06 exige Linux para grupos de procesos/selectores POSIX; el launcher bloquea ejecución incompatible. Una interfaz común no valida una plataforma conjunta. El catálogo sintético no contiene PHI. Las restricciones de Host/Origin/Fetch Metadata, JSON acotado, cancelación, límites de tiempo/trabajadores y errores sin reflejar cuerpos se conservan. Los hooks loopback no demuestran aislamiento exhaustivo del equipo, sus extensiones o todos los procesos.

Para el consumidor público futuro se requieren finalidad/destinatarios, minimización y retención, trazabilidad de fuente y versión, manejo de errores, transporte/autenticidad, límites de recursos y revisión independiente del despliegue real. No se enviaron notas ni imágenes de pacientes a estas APIs.

Ingeniería deberá entregar el grafo exacto del consumidor y pruebas del candidato. Seguridad deberá auditar privacidad, transporte y recursos del entorno previsto.
