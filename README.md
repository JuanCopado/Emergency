# Emergency

Proyecto integrado de soporte clínico para urgencias/UCI. Estado vivo: `STATE.md`. Reglas de trabajo: `CLAUDE.md`.

- `clinical/` — competencia emergency-medicine (borrador v1.35).
- `app/` — PWA.
- `knowledge-graph/` — grafo determinista de módulos/fuentes.
- `rag/` — contrato de recuperación de evidencia.
- `models/` — registro de modelos externos y estado de validación.
- `docs/ARCHITECTURE.md` — arquitectura maestra.
- `docs/GRAPHIFY.md` — integración de Graphify.

El contenido clínico permanece pendiente de validación clínica humana. Los tests técnicos y de regresión no equivalen a validación prospectiva.
