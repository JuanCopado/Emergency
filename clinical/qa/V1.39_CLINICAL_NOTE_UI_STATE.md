# V1.39 CLINICAL NOTE UI STATE

Date: 2026-10-06
Branch: v1.39-clinical-note-diagnostic-support

## Implemented
- React route /clinical-note.
- Seven tabs: História, Exame, MCDT, Problemas, Apoio diagnóstico, Plano, Exportar.
- Pseudonymous encounter workflow.
- History, medication/allergy fields, serial examination and vitals.
- MCDT intake for laboratory, gasometry, ECG, X-ray, CT/MRI, ultrasound/POCUS, microbiology and other.
- File intake with modality suggestion.
- Official/extracted report kept separate from AI interpretation.
- Mandatory pending/accepted/rejected MCDT review state with Accept/Edit/Reject.
- Pending MCDT blocks export.
- Privacy and clinician-review gates block export until resolved.
- Qualitative-confidence diagnostic cards and must-not-miss area.
- Medication-safety warning before actionable treatment.
- Timeline summary.
- Navigation labels in ES/PT/EN/ZH.

## UI tests added
app/src/test/ui.test.tsx checks:
1. Pending MCDT blocks export.
2. Explicit acceptance plus privacy and clinician sign-off is required.
3. Privacy STOP blocks export.

## QA infrastructure
.github/workflows/app-ui-qa.yml runs npm ci, TypeScript typecheck, Vitest and production build.

Clinical QA and App UI QA are separate gates.

## Safety boundary
The browser UI does not perform autonomous image interpretation. Production upload processing must call the existing central clinical modules through a trusted backend adapter. Accepted content only may enter the structured note.
