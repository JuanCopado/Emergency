# V1.41 — Política de fuentes visuales para procedimientos

## Principio
Antes de generar una ilustración desde cero, buscar una imagen anatómica o procedimental reutilizable y legalmente compatible. La imagen externa puede utilizarse como:
1. recurso final reutilizado con atribución/licencia, o
2. referencia anatómica/procedimental para crear una ilustración propia uniforme.

Nunca copiar imágenes protegidas sin permiso.

## Prioridad de fuentes
1. Dominio público.
2. Licencias abiertas compatibles (p. ej. CC BY; revisar condiciones exactas).
3. CC BY-NC-SA u otras licencias restrictivas solo si el uso del proyecto es compatible.
4. Fuente con permiso explícito.
5. Si no existe un recurso reutilizable adecuado, generar imagen propia y someterla a Visual QA.

## Fuentes recomendadas iniciales
- CDC Public Health Image Library (PHIL): muchas imágenes son de dominio público o royalty-free, pero debe verificarse el estado de cada imagen y atribuir CDC/fotógrafo cuando corresponda.
- OpenStax Anatomy & Physiology: revisar la edición y su licencia exacta. Algunas ediciones/recursos recientes son CC BY-NC-SA, por lo que el uso comercial requiere permiso.
- Wikimedia Commons: solo si el archivo concreto tiene licencia compatible y metadatos claros; nunca asumir que todo Commons es dominio público.

## Metadatos obligatorios por imagen externa
- procedure_id
- source_url
- source_title
- source_organization
- author/creator si consta
- license
- license_url
- public_domain: true/false
- attribution_text
- commercial_use_allowed: true/false/unknown
- modification_allowed: true/false/unknown
- retrieved_at
- local_asset_path si se descarga
- intended_use: final_reuse | anatomical_reference | procedural_reference
- clinical_qa_status
- visual_qa_status

## Fail-closed legal
Una imagen NO puede entrar como recurso final si:
- la licencia no está clara;
- exige permiso no obtenido;
- prohíbe el tipo de uso previsto;
- faltan datos mínimos de atribución;
- la fuente es un screenshot de un manual/web sin licencia reutilizable.

## Fail-closed clínico
Aunque la licencia sea válida, la imagen se rechaza si:
- anatomía incorrecta o ambigua;
- lateralidad/orientación incorrecta;
- muestra una técnica distinta a la ficha canónica;
- atraviesa estructuras de riesgo;
- contiene cifras/dosis/profundidades no validadas;
- no permite reconocer el paso crítico.

## Flujo operativo
búsqueda → verificación de licencia → selección → Clinical QA → adaptación/maquetación → Visual QA → aceptación.

La licencia nunca sustituye el Clinical QA, y el Clinical QA nunca sustituye la verificación legal.
