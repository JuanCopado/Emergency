# Expediente para decisión médica del proyecto

El equipo prepara el expediente completo antes de consultar al Dr. Juan Copado Ceballos. Se presenta una decisión independiente por ficha.

| Campo | Contenido que prepara el equipo |
| --- | --- |
| Identidad y alcance | ID canónico, versión examinada, cambio propuesto y consumidores afectados. |
| Evidencia contrastada | Fuentes primarias vigentes, organismo, fecha/versión, enlace, sección o página y fecha de consulta. |
| Aplicabilidad | Población, indicación, producto y entorno. Explicar las discrepancias, sus consecuencias y las incertidumbres. |
| Comprobaciones | Dosis, unidades, concentración, disponibilidad y condiciones de uso cuando proceda. Indicar qué se verificó y qué queda pendiente. |
| Pregunta | ¿Aprueba [cambio concreto] exclusivamente para [alcance identificado]? **SÍ / NO**. |

El equipo registra la respuesta literal del médico, su fecha y el expediente exacto. Una consulta técnica de Farmacia puede aportar datos de producto. Cuando falte evidencia esencial se documenta la laguna y se mantiene pendiente la decisión. La QA posterior y los controles operativos aplicables conservan su función.
