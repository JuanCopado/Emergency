## Exportación Unicode

Se reprodujo la pérdida en un PDF real: `SpO₂ ≤ 92% →` se extraía como `SpO? ? 92% ?`, y `β-bloqueo` como `?-bloqueo`. Se retiró el escritor CP1252/WinAnsi con sustitución y se usa ReportLab con DejaVu Sans Regular/Bold 2.37 embebidas. La fuente libre, licencia, procedencia y hashes se conservan en `assets/fonts/`; no depende de fuentes propietarias o del sistema.

El exportador conserva el gate previo de privacidad/revisión. Escapa el texto antes de pasarlo al marcado de párrafos, calcula el ajuste y la paginación con métricas tipográficas y escribe el archivo solamente tras generar el PDF completo en memoria. Si faltan glifos, devuelve un error con sus códigos Unicode antes de sobrescribir el destino. No hay fallback ASCII ni sustitución silenciosa. DOCX y JSON conservan sus rutas Unicode previas.

Dependencias explícitas:

- Runtime PDF: `python -m pip install -r clinical/requirements.txt` (ReportLab 5.0.1).
- QA: `python -m pip install -r clinical/requirements-test.txt` (añade pypdf 6.20.0 para extracción real; no es dependencia del servidor).
- En esta sesión se usó un venv aislado `%TEMP%\emergency-v142-unicode`, Python 3.14.7. No se modificó Python global.
- Fuentes TrueType/Unicode: https://docs.reportlab.com/reportlab/userguide/ch3_fonts/ ; distribución y checksum DejaVu: https://dejavu-fonts.github.io/Download.html .

## Fuente canónica → JSON → presentación → impresión/PDF

El preámbulo es todo el texto anterior al primer encabezado de nivel dos `## ` del bundle, igual que en `scripts/load_module.py`. El cuerpo específico comprende el encabezado exacto del módulo hasta el siguiente encabezado de nivel dos, excluyendo el propio encabezado. Solo se normalizan finales de línea y espacios exteriores de cada parte.

`build-clinical-guides.mjs` genera `sharedPreamble` y `sectionBody` desde la misma fuente, sin copia editorial. `canonical.ts` ensambla ambas partes una vez en `body`; los consumidores mantienen esa propiedad. El JSON deja de almacenar `body` duplicado, por lo que su esquema interno cambia conjuntamente con su único importador. Las actualizaciones de fuentes deben regenerar el artefacto; la prueba compara los 131 módulos y el JSON versionado con las fuentes para detectar desincronización.

La biblioteca y guías imprimen el mismo DOM que presentan. Los tres algoritmos rápidos (`vf-pvt`, `asystole-pea`, `coma`) antes omitían completamente el módulo canónico: ahora resuelven su `sourceModule` y añaden el módulo completo, incluido el preámbulo, una sola vez. Se retira la promesa de una página para esta salida completa. No se cambian sus instrucciones clínicas resumidas.

Cobertura: los 131 módulos, incluidos procedimientos, farmacología, algoritmos y escalas. No se modifica `generatedProcedures.json`, los módulos fuente, calculadores, migraciones ni visuales.

## Hallazgos y límites

- **P0:** ninguno nuevo confirmado.
- **P1 corregido en este bloque:** los algoritmos rápidos omitían el módulo/preámbulo canónico aun corrigiendo el generador. Las pruebas reales de sus consumidores justifican el ajuste local.

La extracción real y fuentes embebidas están verificadas, pero no se afirma cobertura universal de idiomas, shaping complejo o todo Unicode. Glifos ausentes producen error explícito.
